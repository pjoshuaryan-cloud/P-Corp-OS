What the buttons do

Prepare POST Project prepares the next ingested-and-analyzed POST job as a real Premiere project: bins, imported media, and an empty starting sequence. Transcribe Dialogue runs Premiere's own native transcription on clips with audio. Suggest Smart Selects adds real markers at clean, complete-sentence soundbites found in an already-transcribed clip -- suggestions only, never an automated cut. Apply Starting Exposure is the one action that sets a real grading value: a mild, capped Lumetri Exposure nudge (max ±1 stop) on clips flagged over/underexposed -- a rough starting point only, always meant to be reviewed and adjusted.

Assemble Edit builds a cut to music from an edit plan. In P Corp OS, plan the edit first (pick a style from your reference edits and a music track): it chooses the cut points on the song's hits in that style's rhythm and writes a plan. This button then builds it in a NEW sequence: video-only hard cuts at exact frames, with the music cut on its own audio track. It adds no effects, flashes or sound effects. Which moment of each clip is used is a suggestion, not a validated choice -- review it, and watch the preview file first if you can. It never changes an existing sequence. Save your project first.

Assemble Rough Cut builds a real sequence -- it actually places clips on a timeline, not just markers. It reads the clip order from your own timeline (the sequence named after the shoot), takes each clip's single suggested moment from P Corp OS (a composition pick -- it has NOT been shown to match your taste, so expect to swap some) and cuts them together in that order in a new sequence with the same format as yours. The pieces it creates are filed in a "Rough Cut Pieces" bin. It is a mechanical assembly, not a finished edit: always review and re-edit it. It always creates a new, separately-named sequence and never changes an existing one. Save your project first.
